# Índice de evidencias

PNG originales de la aplicación local en Firefox. Cuenta ficticia de
demostración; no contienen contraseñas, JWT ni API keys. Su orden de presentación
y explicación está en [el informe](../entrega-final.md#recorrido-visual-ordenado).

| Orden | Pantalla |
|---:|---|
| 01–02 | Inicio de sesión y registro |
| 03–05 | Fuentes, búsqueda en catálogo y fuentes importadas |
| 06–08 | Feed, prioridades y portada de un medio |
| 09–11 | Lectura, espera y resumen real por Ollama |
| 12–13 | Archivo, recortes y estadísticas |
| 14–15 | Perfil, temas y ajustes de lectura |
| 16–18 | Motor local, API externa y opción Claude (sin claves) |
| 19 | Ventana de ancho reducido |
| 20–21 | Pregunta contextual real y digest |
| 22–23 | Tema claro y diagnóstico del Agente |

`manifest.json` describe las capturas y sus hashes. Los archivos `.txt` guardan
resultados de pruebas y diagnóstico sin secretos. No se incluye ninguna base
de datos ni el estado de sesión de la automatización.

Las imágenes/noticias de los medios son evidencia académica de su visualización;
los nombres de fuente y enlaces se conservan para no atribuir al portal esos contenidos.
